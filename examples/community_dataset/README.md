# Community dataset example

This directory contains metadata-only examples for the community manifest
schema. No video files are included. The local relative paths are placeholders;
schema validation intentionally does not download or require media.

Validate with:

    pipeline validate-manifest examples/community_dataset/manifest.jsonl

The rows demonstrate community-submitted, reviewed, and benchmark-eligible
statuses, public URL and local path locators, and explicit absence of prompts
or reference images.

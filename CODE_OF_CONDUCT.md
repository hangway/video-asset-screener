# Code of Conduct

This project follows the Contributor Covenant Code of Conduct, version 2.1.

## Our standards

Contributors are expected to be respectful, constructive, inclusive, and
professional. Harassment, discrimination, personal attacks, intimidation,
unwelcome sexual attention, doxxing, and publishing private information are not
acceptable.

## Enforcement

Maintainers may remove or edit contributions, close discussions, or restrict
participation when behavior violates this code. Report conduct concerns
privately to project maintainers; do not include sensitive personal information
in a public issue.

The full Contributor Covenant is available at:
https://www.contributor-covenant.org/version/2/1/code_of_conduct/

# Security policy

Please report security issues privately through GitHub's private vulnerability
reporting for this repository. Do not open a public issue for a vulnerability
that could expose users or contributors.

Report code vulnerabilities, unsafe file parsing, path traversal, malicious
video or metadata inputs, accidental personal-data exposure, or leaked
credentials, tokens, and private URLs. Include a description, reproduction
steps, affected commit or version, and any safe proof of concept. Do not attach
private media or secrets.

Ordinary disagreements about model quality, taxonomy interpretation, or
benchmark results belong in a normal GitHub issue or pull request, not the
security channel.
